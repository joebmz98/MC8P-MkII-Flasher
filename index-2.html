MC8P HID firmware flasher

Update the black pill inside your MC8P over USB using the WeAct HID bootloader.

Ready.

This browser can't access USB HID devices. Use Chrome, Edge or another Chromium-based browser on a desktop.

  1. Enter HID bootloader mode. Hold BOOT0, tap NRST, then release BOOT0. You can also hold BOOT0 while plugging in USB.
  2. Connect. Select the STM32 HID Bootloader (VID 0483, PID 572A) in the browser's device list.
  3. Flash. The board restarts into the new firmware when it finishes.
  4. Reset if needed. If the OLED stays dark after flashing, tap NRST once. Wait ~10 s for the boot screen.
Must match the bootloader currently flashed on the chip. The WeAct HID bootloader reserves 16 KB, so the app starts at 0x08004000. Rebuild your sketch with -DVECT_TAB_OFFSET=0x4000.
